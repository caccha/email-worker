部署步骤

  1. 创建 Cloudflare D1 数据库 email-db
  2. 修改 wrangler.toml 填入 database_id
  3. 运行 npx wrangler d1 execute email-db --remote --file=database/schema.sql
  4. 运行 npx wrangler deploy
  5. 配置 DNS MX 记录：@ MX 10 mx.cloudflare.com
  6. 在 Cloudflare Dashboard → Email → Routes 设置 Catch-all
